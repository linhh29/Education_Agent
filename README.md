# 好奇心伙伴

面向 4–7 岁儿童及家长的本机文字 AI 演示。孩子可以自由提问、追问、说没听懂、要求例子或换话题；家长可以回看原话、修订记录、留下提醒，并查看一项按需出现的亲子观察建议。

## 启动

使用 Python 3.9+，仅依赖标准库，不需要安装 npm 包。当前工作目录已实际验证：

```bash
cd /Users/qcw/Desktop/Education_Agent/Educational_Agent_Code/Education_Agent
python3 app.py
```

打开 [孩子端](http://127.0.0.1:8787/child)、[家长端](http://127.0.0.1:8787/parent) 或 [创建档案](http://127.0.0.1:8787/setup?new=1)。服务只绑定本机，同一数据文件只允许一个运行进程；端口占用时可以使用 `PORT=8791 python3 app.py`。停止服务按 Ctrl+C。

后端从 `/Users/qcw/.config/education-agent/dashscope_api_key` 读取已配置的 Key。不要把 Key 填进页面或源码；文件缺失、模型权限不足或预算不足时，页面会保留问题并提示原因，不生成预写答案。

## 从页面演示

1. 创建演示档案，或选择已有档案。只使用合成昵称与资料。
2. 输入一个自由问题。可以接着问，或点“没听懂”“简单一点”“举个例子”“详细一点”；也可以直接要求故事。
3. 点“开启新对话”，旧对话保留在记录里。回答中可停止；停止或失败后点“再试一次”，原问题只保留一份。
4. 进入“家长看看”，打开近期问题查看完整对话，打开理解线索查看对应孩子原话与当时回答。
5. 修改记录或添加、修改家长提醒；下一次相关回答会读取最新有效资料。记录详情先展示原话与修改入口，完整交流和修订历史可以展开；偏好可由家长明确适用范围。
6. 查看“一起发现”的建议。有合适的安全共同观察才显示，操作前由家长确认环境。

当前本机可选择“南南（合成）”继续已有对话，或选择“果果（演示）”开始新对话并回看积木相关原话与家长修订。资料由成人通过正常页面合成，不是真实家庭成果。新 checkout 不包含这些本地记录，创建空白档案即可复现产品。

普通界面不显示测试档案、录制入口、预算明细、模型参考快照或未验证的朗读按钮。开发人员确需核查旧测试资料时，可显式打开 `/setup?dev=1`；测试资料保留在原数据文件里，没有删除或改成普通演示成果。

## 模型与记忆

当前正常页面使用 `qwen3.8-max-0902`，服务地址为 DashScope 的 OpenAI 兼容接口。配置集中在 [config/runtime.json](config/runtime.json)：非思考模式、最大输出 1800 token、温度 0.5、网络超时 28 秒、输入字节上限 42000。`thinking_budget` 只在开启思考时生效。

解释、话题、少量有依据的个体记录及可选建议仍由一次问答调用共同生成，追问与反馈共用逻辑。当本档案存在可用记忆或过去会话时，先用同一个 Qwen 做一次有界语义选取：最多选择四条相关个体记录和两个必要的过去会话；知识问题有历史指代时也可取对应小结或原文。空目录会跳过选取；“没听懂、简单一点、举个例子、详细一点”按钮明确针对最新回答，在上下文、选取方式和资料版本仍有效时复用选择，少等一次调用。自由输入、换话题、新会话、历史回顾、检索失败或家长资料变化时仍按需选取；没有通过题目关键词判断是否跳过。没有答案模板、额外路由、重复审核或自动重试链路。

实际对话先落盘。语义目录从当前存储临时构建，覆盖同档案的有效记录；一般讲法与话题、会话内讲法区分，不再按家长编辑和双字重合截取前十二条。取回 ID 后重新核对内容、版本和状态。目录上限为 80 项、28000 字节；超限或检索失败会说明无法核对历史，普通问答仍可继续，不能假装采用了家长资料。权限和预算错误直接停止。

个体记录仍在 `memoryItems`，有原话、来源、版本、作用范围和新旧关系。LLM 按语义提出困惑、有限理解或偏好，可以不新增；重复、补充、本次变化和冲突分别记录，不自动改写家长意见、消除旧困惑或恢复撤回项。系统解释过不等于孩子理解了；原话存在也不证明整理判断正确。

会话结束或家长点击“整理这次探索”时，后台生成简短的主题、明确困难、尝试过的讲法和孩子提过的追问，保存于现有会话中。相同来源不重复整理，最多两个本地整理任务；重启后不续写旧任务。困难和追问展示有来源的孩子原话，可点回完整对话。追问是历史表达，不自动当作尚未解决或必须确认理解的任务；没有后续表达不代表没懂。语义选取为 400 token/网络超时 8 秒，整理为 1100 token/网络超时 18 秒，均使用原模型和共同预算；网络超时不是全流程等待上限；具体限制在 `memory_support.py`，生成模型配置不变。

自动偏好没有支持跨会话范围的原话时，仅适用当前会话；旧自动偏好也保守投影为会话范围，不改写存储历史。选中记录附带短原话、来源、范围与证据类型。修改、撤回或删除资料会停止尚在生成的旧资料回答，使依赖旧版本的派生记录、小结、建议和后续生成上下文失效，同时保留孩子独立表达形成的有效证据；不会回退展示更早的旧建议。独立或依赖上下文的语义判断仍可能出错。原始对话保留用于回看。服务端保存实际提供的记录/探索版本；模型自报的 `usedMemoryIds` 仅是辅助证据，不证明遵循。刷新及重启保留状态，删除仍可恢复。已发到供应商的请求可能继续计费，停止保证迟到结果不写入对话。

这一实现选择性参考 [AMA a770f9aa](https://github.com/Sherlockwz/AMA/tree/a770f9aaef527ae589bf13015260cd24eda2d58c) 的原文、个体信息、探索过程及有效状态维护机制。没有安装其框架、OpenClaw、FAISS、sidecar 或新的云 embedding 服务，也没有复制研究代码。

## 本地数据与费用

- `data/demo-db.json`：档案、对话、记忆、修订历史及请求状态，按档案归属隔离，已被 Git 忽略。
- `logs/llm-usage.json`：调用次数、返回用量、耗时、费用估算与未知费用上界，不保存 Key 或提示词，已被 Git 忽略。
- `EDUCATION_AGENT_DB=/tmp/another-demo.json python3 app.py` 可使用独立数据文件；模型预算账本仍由本仓库共同使用。

预算沿用已确认占用 ¥2.735356；本轮最多 ¥47、总额最多 ¥50，因此有效上限 ¥49.735356。每次发请求前按输入 UTF-8 字节和输出上限预留费用，返回用量后按输入 ¥12/百万 token、输出 ¥36/百万 token 估算，不计缓存折扣；未知用量保留全部预留额，不按零计。账本包含后续从页面发生的消费，请保留该文件以保持累计预算一致。它是保守估算，最终账单以供应商为准。若确认有本轮账本外的新消费，将其加到配置的 `prior_cny` 后重启；占用基数只会上调，授权上限不会随之扩大。

```bash
python3 -m unittest discover -s tests -p 'test_companion.py'
python3 -m unittest discover -s tests -p 'test_memory_lifecycle.py'
```

本轮运行当前产品与记忆生命周期的相关离线回归，覆盖存储、归属、幂等、停止、版本失效、检索失败、在途更新、摘要来源和预算；没有重跑整套收费案例。真实模型与正常页面另行检查，结果和实际截图见 [docs/CODEX_HANDOFF.md](docs/CODEX_HANDOFF.md)。来源校验和测试通过都不代表回答全部正确，也不能证明适合真实儿童长期使用。

麦克风及云语音未启用。原有设备朗读能力仅在开发入口保留，当前环境未实测，仅允许浏览器标记为本机的中文声音；普通界面提供文字体验。没有额外搜索或收费服务。本机演示不含家长登录保护，不能直接作为公开服务部署。

## 代码入口

`app.py` 保留原 Python Web 服务和历史纯逻辑；正常 API 委托给 `companion.py` 的问答、事务存储、后台整理与预算控制；`memory_support.py` 放记忆粒度、来源和有效性规则。`static/app.js`、`static/styles.css`、`static/index.html` 是当前唯一产品前端。

`/video-demo` 与 `data/showcase-child-24days.json` 是历史只读预设录制内容，明确标注且不进入普通档案。旧架构文档、`EDUCATION_AGENT_REPORT.md` 和旧真实回归脚本描述的是先前版本；旧模型调用入口已停用，当前实现与交付以本 README 和交接摘要为准。
