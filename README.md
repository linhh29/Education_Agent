# 好奇心伙伴

面向 4–7 岁孩子及家长的本机 AI 演示：自由提问、自然追问、语音转文字、回答朗读，以及可回到原话的家长记录。目标是听得懂、愿意继续问；允许合理简化与形象表达，不把聊天变成考试。

## 启动

Python 3.9+，仅使用标准库，无需安装 npm 或 Python 第三方依赖。在这台 Mac 上已验证：

```bash
cd /Users/qcw/Desktop/Education_Agent/Educational_Agent_Code/Education_Agent
python3 app.py
```

打开 [好奇心伙伴](http://127.0.0.1:8787/child)。服务只绑定本机；同一数据文件只允许一个进程。Ctrl+C 停止。后端从 `/Users/qcw/.config/education-agent/dashscope_api_key` 读取 Key，页面不接收密钥。新 checkout 不含本机资料；从“＋ 新建档案”开始即可。

## 使用与演示

2026-10-02 家长网页整合为“聊天记录”“家长问答”“孩子档案”。新增独立的家长文字问答、待保存草稿及活动调整入口；孩子端模型、prompt、memory 与语音逻辑保持原样。实际验证范围及局限见 [交接摘要](docs/CODEX_HANDOFF.md)。

1. 选择“现场开始 · 示例”从空白开始，或“小芽 · 示例”回看正常页面形成的记录。示例标识只在档案选择处显示，原始档案名与资料保留。
2. 打字，或点“说话”并主动允许麦克风，讲完点“结束录音”。识别结果可以修改，点“发送”才开始问答；也支持“选择音频”。一次最多 60 秒，不会自动重新开麦。
3. 自由追问，或点“没听懂”“简单一点”“举个例子”“详细一点”。回答可停止，失败可手动重试；“开启新对话”保存旧会话。
4. 回答下点“朗读”，播放时显示“停止朗读”，停止或结束后回到“朗读”；可用有效缓存重播。朗读读取屏幕上已经保存的正文，不重新生成答案。浏览器阻止播放时会显示再次点击入口。
5. 进入“家长 → 聊天记录”，查看近期会话及一项有效亲子建议。完整历史和搜索仍可访问，点击进入统一聊天详情；所有“查看原话”定位同一份真实消息。打开或刷新页面不会生成新建议。
6. “家长问答”可以问近期话题、明确困惑、记录依据或共同活动，也可继续调整材料。家长交流单独保存；提醒或修改先给可编辑草稿，点“保存”才生效。支持停止和失败重试。
7. “孩子档案”以紧凑列表展示完整正文，点正文或“编辑”查看依据、适用范围与修订历史。旧会话限定、撤回或依据变化的记录在“其他记录”中。保留添加、撤回、回收和恢复；修改冲突保留草稿。

这些资料由成人合成，不是真实家庭成果。已有档案保留；测试档案、旧录制入口、内部 ID、调用和费用明细不放在普通界面。开发核查可显式访问 `/setup?dev=1`。完整的 5–7 分钟流程、故障备用与设备检查见 [演示手册](docs/INVESTOR_DEMO.md)，真实结果见 [交接摘要](docs/CODEX_HANDOFF.md)。

## 模型与记忆

配置集中在 [config/runtime.json](config/runtime.json)，不会静默换模型或返回预写业务答案。

| 环节 | 正常页面配置 |
| --- | --- |
| 问答 | `qwen3.8-max-0902`，非思考，temperature 0.5，输出上限 1800 token，网络超时 28 秒，输入上限 42000 字节 |
| 记忆语义选取 / 会话整理 | 同一个 Qwen；分别 400 token / 8 秒、1100 token / 18 秒，限制见 `memory_support.py` |
| 家长选取 / 家长回答 | 同一个 Qwen；独立成人提示，500 token / 10 秒、1600 token / 28 秒，限制集中于 `parent_prompts.py`；没有家长语音 |
| ASR | `qwen3-asr-flash-2026-02-10`，中文识别；浏览器将音频真正转换为单声道 16 kHz PCM16 WAV 后上传 |
| TTS | `qwen3-tts-flash-2025-11-27`，Serena，Chinese；朗读正文按需分段，返回实际音频 |
| 语音网络 | 北京 DashScope，单次网络超时 25 秒；两个并发语音任务。网络超时并不等于全流程等待上限 |

原话保存在 `messages`；`memoryItems` 实际类型为困惑、有限理解、明确偏好、家长提醒。孩子的前三类由同一次回答模型按语义提出，代码核对原话、归属、范围和版本；提问不自动算理解。家长提醒直接保存。

有有效记忆或过去会话时，同模型从有界目录选择最多四条记录和两个必要会话；空目录跳过，部分针对最新回答的反馈按钮可复用仍有效的选择。没有 embedding 或向量库。取回后再校验有效性，将少量证据与最近对话交给回答模型；目录过大或选取失败会明确提示历史资料未完整可用。结束会话或手动整理才额外生成探索小结。

修订、撤回、删除会递增版本，并停止旧版本及其依赖小结、建议和回答上下文的使用；保留有效独立原话。原始历史仍可回看。模型可能误判语义，也可能收到提醒却没有采用指定讲法；提供了资料不等于证明遵循。没有新增审核链或 memory 框架。

家长查询使用 `parent_support.py` 的独立接口，借用现有有效性检查。先按语义选择最多6条记录和4段会话，再按上海日期实际过滤原话；“最近”默认含今天7天。有界目录最多40条记录、40个会话，容量截断会提示，不能据未取到资料断言孩子从未表达过。家长记录在 `parentMessages` / `parentRequests`，不进入孩子 messages、学习证据或小结。模型调用在存储锁外执行；活动依赖当前实际使用的来源和版本，修订/撤回后退出当前展示。仅显式保存草稿调用既有 `add_reminder` / `update_memory`。

## 本地资料与费用

- `data/demo-db.json`：档案、对话、记忆、修订历史和请求状态，刷新、重启保留，按档案隔离。
- `data/demo-db-speech-cache/`：已交付回答的朗读缓存，24 小时有效；启动或后续语音访问时清理过期文件。
- `data/synthetic-audio/`：本轮明确标记的合成测试音频。真实麦克风原始音频只在处理期间保留于内存，不落盘；未提交转写暂存 30 分钟，已发送的转写来源随原话保存。
- `logs/llm-usage.json`：共同费用账本，记录用途、用量、耗时和未知预留，不保存 Key、完整提示词或临时媒体 URL。

上述本地资料均不提交 Git。独立数据文件可用 `EDUCATION_AGENT_DB=/tmp/another-demo.json python3 app.py`；仍使用同一预算账本，不可用换库绕过费用累计。

有效累计上限为 ¥49.735356（原确认 ¥2.735356 + 新增最多 ¥47，且总额不超 ¥50）。调用前预留、返回实际用量后按配置单价估算；未知用量保留预留，不按零计。云语音累计最多 ¥5，全部自动调用保留至少 ¥5 总余额。不要重置账本；实际供应商账单可能不同。ASR 单价 ¥0.00022/秒，TTS ¥0.8/万计费字符；TTS 中文计费字符可多于文本长度，预留采用 UTF-8 字节加余量。

官方资料：[Qwen 配置](https://help.aliyun.com/zh/model-studio/qwen3-8-max)、[ASR 接口](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)、[TTS 接口](https://help.aliyun.com/zh/model-studio/qwen-tts-api)、[价格](https://help.aliyun.com/zh/model-studio/model-pricing)。

## 验证与边界

```bash
python3 -m unittest discover -s tests -p 'test_*.py'
node --test tests/test_voice_ui.cjs tests/test_presentation.cjs
```

已验证真实云 ASR、文字回答、TTS 和浏览器播放事件，以及页面家长修订、恢复和网络中断后的文字保留。工程回归使用受控供应商，不计入真实质量结论。真实麦克风、扬声器听感、儿童口音与噪声环境尚需人工确认；窄屏检查不等于真实手机语音测试。AI 仍会解释过度、讲得偏长或未充分采用提醒，不保证每条回答正确，不代表真实儿童长期效果已验证。

只用于本机由成人操作的合成资料演示；没有家长登录保护，不作为公网服务部署。没有搜索、声音克隆或其他新增付费服务。

`app.py` 为 Web 服务；`companion.py` 管问答、存储与账本；`memory_support.py` 管记忆有效性；`speech_support.py` 与 `static/voice.js` 接入同一产品语音流程。`static/app.js` 与 `static/parent.js` 组成同一正常产品界面；后者只处理家长交互。历史 `/video-demo` 与预设录制资料保留但不作本轮实测证据。
