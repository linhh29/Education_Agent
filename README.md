# 好奇心伙伴

面向 4–7 岁儿童及家长的本机文字 AI 演示。孩子可以自由提问、追问、说没听懂、要求例子或换话题；家长可以回看原话、修订记录、留下提醒，并查看一项按需出现的亲子观察建议。

## 启动

使用 Python 3.9+，仅依赖标准库，不需要安装 npm 包。当前工作目录已实际验证：

```bash
cd /Users/qcw/Desktop/Education_Agent/Educational_Agent_Code/Education_Agent
python3 app.py
```

打开 [孩子端](http://127.0.0.1:8787/child)、[家长端](http://127.0.0.1:8787/parent) 或 [创建档案](http://127.0.0.1:8787/setup?new=1)。服务只绑定本机，同一数据文件只允许一个运行进程；端口占用时可以使用 `PORT=8791 python3 app.py`。停止服务按 Ctrl+C。

后端从 `/Users/qcw/.config/education-agent/dashscope_api_key` 读取已配置的 Key。不要把 Key 填进页面或源码；文件缺失、模型权限不足或预算不足时，页面会保留问题并提示原因，不生成预写答案。

## 从页面演示

1. 创建“普通合成演示”档案，或选择已有档案。只使用合成昵称与资料。
2. 输入一个自由问题。可以接着问，或点“没听懂”“简单一点”“举个例子”“详细一点”；也可以直接要求故事。
3. 点“结束这次，开始新的”，旧对话保留在记录里。回答中可停止；停止或失败后点“再试一次”，原问题只保留一份。
4. 进入“家长看看”，打开近期问题查看完整对话，打开理解线索查看对应孩子原话与当时回答。
5. 修改记录或添加、修改家长提醒；下一次相关回答会读取最新有效资料。对话详情可展开查看模型报告使用的提醒或原话快照。
6. 查看“一起发现”的建议。有合适的安全共同观察才显示，操作前由家长确认环境。

当前本机的“小禾（合成）”资料由正常页面实际生成，明确是合成演示，不能作为真实家庭成果。新 checkout 不包含这些本地记录，创建空白档案即可复现产品。开发验证档案通过设置页“开发验证资料”进入，普通档案选择器不显示测试档案。

## 模型与记忆

当前正常页面使用 `qwen3.8-max-0902`，服务地址为 DashScope 的 OpenAI 兼容接口。配置集中在 [config/runtime.json](config/runtime.json)：非思考模式、最大输出 1800 token、温度 0.5、网络超时 28 秒、输入字节上限 42000。`thinking_budget` 只在开启思考时生效；本次试验后选择非思考模式。

一次问题只调用一次模型，同时生成解释、当前话题、少量有原话依据的理解/困惑/偏好，以及可选建议。追问和反馈共用该逻辑。没有规划、重复审核、自动修复或自动重试链路；没有题目专用答案。格式异常会提示手动重试。

实际对话先落盘。候选记忆按当前档案、有效状态和话题做有界选取，由模型按语义决定是否使用；回答不是长期答案缓存。普通提问不会自动视为“已经理解”，系统解释过也不等于孩子理解了。理解线索保留准确原话及来源会话，家长修订不会改写原始对话；家长提醒影响讲法，不改变科学事实。

修改、撤回或删除资料会停止尚在生成的旧资料回答。刷新及重启会保留记录；删除记录、会话和档案都可从页面恢复。删除来源会话同时移除关联原话与记忆。已发到供应商的请求可能仍产生费用，停止仅保证迟到的回答不写入对话。

