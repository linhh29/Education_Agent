# 好奇心伙伴

面向4–7岁孩子及家长的本机AI演示。孩子自由提问和追问；家长查看原话、询问记录依据、保存提醒。示例资料由成人合成，不代表真实家庭使用成果。

## 启动

Python 3.9+，仅使用标准库。在项目目录运行：

```bash
PORT=8788 EDUCATION_AGENT_DB=data/local-investor-rc32-db.json PYTHONDONTWRITEBYTECODE=1 python3 app.py
```

打开 [好奇心伙伴](http://127.0.0.1:8788/child)。启动前先停止同一数据库的旧实例，避免重复运行；Ctrl+C停止服务。仅监听本机127.0.0.1。旧8787服务不属于当前入口，不要批量结束进程。

后端从 `/Users/qcw/.config/education-agent/dashscope_api_key` 读取已有Key，前端不接收密钥。代码检出不包含本机资料；缺少演示库时会创建初始档案，可以从“＋ 新建档案”开始。

## 使用

- 选“现场开始 · 示例”从空白开始，或“小芽 · 示例”查看已保存的对话。
- “一起聊”支持文字、语音转写及后续追问。转写需核对并点击发送；回答可朗读、停止和重播。真实麦克风需本人主动授权。
- “聊天记录”可搜索、回看原话及已有亲子建议；“家长问答”可询问记录依据，提醒草稿经保存才生效。
- “孩子档案”直接展示记录内容，编辑入口在旁边。会话提醒需明确选择聊天；修改、撤回、回收站和修订历史均在原入口。回收站“放回档案”和历史“恢复到这个版本”是不同操作；发生冲突时先查看最新内容，再核对保留的草稿。

三处家长入口固定为“聊天记录／家长问答／孩子档案”。AI身份和示例标识保留；有明确 `kind=test` 标记的档案只在已有开发入口 `/setup?dev=1` 展示，不根据名字过滤或删除资料。

## 本地资料与配置

- `data/local-investor-rc32-db.json`：当前演示档案、聊天、提醒、历史和请求状态；刷新与重启保留。
- `data/local-investor-rc32-db-speech-cache/`：当前演示的朗读缓存；过期后按既有规则清理。
- `logs/llm-usage.json`：共享费用账本。不要删除或重置；切换数据库不会重置预算。
- `config/runtime.json`：集中模型与费用限制。当前文字模型为 `qwen3.8-max-0902`，非思考模式；本次服务更新没有再修改模型、prompt、memory或语音生命周期。

本机数据、音频、截图与Key均不提交Git。原始 `data/demo-db.json`、历史验证资料和报告保留，不是需要清理的垃圾。
