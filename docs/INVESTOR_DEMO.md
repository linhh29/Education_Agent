# 投资人演示手册

只由成人使用合成资料，在本机操作或屏幕共享。入口 http://127.0.0.1:8787/child ，正常启动命令见 README。选择“现场开始（合成）”自由开始；“小芽（合成演示）”已有真实云服务生成的八问、三个会话，适合回看。所有历史回答明确作为既有记录展示。

## 5–7 分钟主演示

| 时间 | 从页面操作 | 展示重点 |
| --- | --- | --- |
| 0:00–1:00 | 选择空白档案，问身边真正好奇的问题；点击“说话”、允许麦克风、说完点“结束录音”，核对转写后发送 | 问题没有预设答案；可编辑识别文字，也可直接打字 |
| 1:00–2:00 | 接着说“没听懂，举个例子”，或自然追问；点击回答下的“朗读”，试一次停止和重播 | 同一对话理解上下文；朗读的就是保存的回答 |
| 2:00–3:30 | 进入“家长看看”，点近期问题看完整交流；若现场没有产生个体记录，可明确切到“小芽（合成演示）”的既有记录，打开“孩子表达了什么” | 原话“我还是没听懂，能举个例子吗？”与家长纠正后的判断分开保存，不宣称孩子已掌握 |
| 3:30–5:00 | 在家长提醒“物体怎样站稳”中修改希望怎样讲并保存；回“一起聊”，点“开启新对话”，问一个相关的新问题 | 修改的提醒用于下一次相关上下文；能否采用具体讲法仍由实际回答体现，不作保证 |
| 5:00–6:30 | 朗读新回答，查看家长端“一起发现”及其来源；回看已保存原话 | 相关、简单、由家长陪同的共同观察；没有合适建议可以不显示 |

本轮实际走过的链路：合成语音问积木 → 合成语音说没懂 → 家长修订困惑与提醒 → 新会话问书 → 采用提醒 v2 并朗读 → 再开会话用语音问积木，模型收到 v2，但没有采用书的指定例子。后一个结果保留，不能说提醒每次都被严格执行。

当前小芽家长端的实际建议是“比一比平放和立起的书”：拿同一本书，先平放、再立起，轻推比较是否容易翻倒；在低处桌面进行，不用重物。来源链接回到最后一次语音问积木的会话。这一轮回答正文没有换成书的例子，但建议采用了书与低处操作的提醒。家长先确认环境与书的大小，不要求现场完成实验；后续建议会随新问题更新。

## 故障备用

- 麦克风拒绝或 ASR 失败：选“取消”或“改为文字输入”，在同一输入框打字。识别状态不明时先“查看识别状态”，避免重复上传。转写过期仍可保留文字，改为文字发送。
- 朗读失败：屏幕回答保留，重试只处理朗读；浏览器阻止自动播放时再点播放。缓存有效期内重播不会再次合成。
- 网络或模型不可用：告诉观众现在查看既有记录，切到小芽的“记录”展示实际问答与修订；没有静默备用答案。服务恢复后用“再试一次”或恢复的输入继续。
- 没有设备条件时，可以点击“选择音频”，使用 `data/synthetic-audio/blocks-question-serena.wav` 或 `followup-serena.wav`；务必说明这是系统生成的合成声音，不能称为真实儿童收音验证。

本轮没有安全可用的浏览器区域录像工具，未生成新视频；可使用 `docs/screenshots/investor-*.jpg` 真实截图和可回看的记录。旧 `/video-demo` 不是本轮彩排录像。

## 演示前 5–10 分钟本人检查

1. 打开入口，选择空白档案。主动点击“说话”，批准这一个页面的麦克风权限，说一句自由问题，结束后看文字是否符合所说内容；先改一个词再发送。
2. 接着说“我没听懂，换个说法”，核对上下文。看回答是否让人听懂、愿意继续聊，不按固定词句打分；发现讲偏可以直接纠正或追问。
3. 点“朗读”，亲耳确认扬声器/耳机音量、普通话听感与屏幕内容；停止、重播，再切档确认声音停止。工程已验证播放事件，实际听感未替你确认。
4. 家长端查看一条原话与修改记录，读一项亲子建议，确认内容与环境合适；用余下时间按上表走完主要步骤。

确认收音、听感及几段内容后即可用于本机场景演示；这不代表真实儿童长期使用效果或嘈杂环境识别能力已经验证。
