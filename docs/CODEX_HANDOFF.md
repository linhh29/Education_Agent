## 当前 memory 的真实实现

依据为 `companion.py`、`memory_support.py` 和合成数据库，不以旧 README 推断。`app.py:Handler.product_api` 把正常 API 交给 `CompanionService`，旧多阶段模型入口不在正常问答链上。

- 原始孩子提问和 AI 回答保存在 `messages`：ID、档案、会话、角色、text、状态、时间；回答另存实际提供的记忆/小结版本、上下文消息 ID、模型与调用耗时。
- 个体记录保存在 `memoryItems`，实际类型只有 `confusion / understanding / preference / reminder`。前三类由同一次回答模型提出，最多两条；`chat` 核对本轮逐字原话、枚举、长度、归属，决定是否保存。提问本身只进 messages，不是一种理解卡。LLM 负责语义区分，代码校验不能证明摘要正确。
- 共有字段为档案/会话 ID、kind、topic、summary、quote、sourceMessageIds、scope、status、version、来源角色、时间、history。自动记录还有 evidenceType、evidenceBasis、scopeEvidence、memoryDependencies、contextMessageIds、relation、relatedMemoryIds；家长提醒由 `add_reminder` 直接保存，不经模型批准，没有孩子来源消息。
- 会话探索保存在 `conversations.exploration`：topic、focus、difficulties、attempts、兼容字段 openQuestions（孩子历史追问，不是未解决任务），以及来源、记忆版本、fingerprint、状态、版本、partial。档案中的年龄、兴趣、熟悉物品与讲法偏好也作为上下文输入，不是模型从孩子聊天推断出的卡片。

`begin_chat` 取当前会话最近 14 条有效消息，并按同档案、状态、范围构建完整有效目录。`prepare_context` 调用同一个 Qwen 按语义选择最多 4 条个体记录、2 个必要会话；**没有 embedding、向量库或关键词召回**。记录页的搜索是简单文本包含匹配，与模型检索不同。换一种说法能否命中取决于 LLM 对问题、最近 4 条对话及目录的理解，不保证命中。目录只带会话首问、末问和主要 focus，可能漏掉中间话题。

回答模型实际收到 profile、最近对话、currentText、replyStyle、选中记录的短原话/来源/证据/有效范围，以及选中会话的有效小结或最近 10 条有效原文。目录先给选取模型，不把全部记忆正文送给回答模型。目录上限 80 项或 28000 字节；超限明确降级，原数据不删除。空目录不调用选取；最新回答的反馈按钮在版本和历史选取方式仍有效时复用，自由输入仍按需选取。明确历史依据缺失时提示不能假装记得。

`chat` 生成个体记录不增加一次独立调用。`end_conversation → request_summary` 或手动整理才在后台额外调用同模型；最多取最近 30 条消息、每条 1000 字，来源不变复用，最多两个任务。无额外审核链或自动重试。

`effective_scope` 将没有跨会话原话依据的自动偏好限制在本会话，旧数据只改变使用投影、不改写历史。`update_memory / invalidate_pending / validity` 按记录版本、来源、上下文传播失效，停止使用旧派生卡、小结、建议和回答上下文；原话仍在页面可看。被标为独立表达且有孩子原话的卡片保留，但“独立”由模型判断，仍可能误判。恢复也递增版本，不能让旧依赖静默重新生效。

**实际发现及修正。**

1. 空目录原本已经跳过语义选取，保留。已有记录时，同题反馈仍重复选取；现在反馈按钮携带明确动作与当前回答 ID，`begin_chat` 核对同档案、同会话、最新回答、上下文、修订号和记录版本，`prepare_context` 重新读取有效内容后复用。后台固定反馈动作只用于标明用户操作，不是题目关键词或答案模板。自由输入即使写“简单点”，也不会仅按文字绕过选择。
2. 新话题、新会话、历史回顾、资料变化或上次选取失败仍按需选取。过期按钮明确报错；停止后反馈按钮暂时禁用，手动重试保留原动作及同一条问题。不增加路由模型或自动重试。
3. 基线“没听懂”后主要换物品重复结果，举例铺垫较长；通用提示改为先说核心关系及必要条件，细节随追问展开，不连堆类比。另有一条核对问题被整理成理解线索，因此强化提问、猜想和明确陈述的区分；对应重问没有新增这条理解判断。没有逐题规则、字符截断或固定句数要求。
4. 一份四条有来源的讲法因最多三条校验而整份失败，放宽为有界接受合理的小结；仍保留来源、单项长度、输出和超时限制。原失败会话从页面重新整理成功。
