## 实际做成了什么

先打开并使用了原型，检查原问答、多阶段模型链、记忆、家长页面和录制示例。随后保留原 Python 服务、JSON 存储结构及 HTML/CSS/JavaScript 技术栈，把正常问答合并为一次模型调用。没有清空仓库，也没有长期并存的第二套应用。

孩子端支持自由提问、自然追问、没听懂、简单一点、举例、详细一点和直接要求故事；支持停止、手动重试、结束会话及开始新的。长回答先显示最新问题与回答开头，可以上下滚动或点「继续往下看」。输入和操作成功、失败、等待状态均可见。

家长端显示近期问题原话、话题、谨慎的理解/困惑/偏好线索、编辑入口、家长提醒和一项可选亲子建议。建议链接到来源聊天，不强制每轮生成。记录详情把原话依据与可修改的整理结果放在一起，原始对话不随家长编辑改写。修改、撤回、恢复上一版本、删除及回收站恢复都有页面入口。

界面采用浅色背景、统一字体与间距、克制的绿色。模型、运行模式、数据去向及预算说明在页脚次级入口；主页面没有 JSON、内部 ID、Token 或调用链控制台。AI 身份、合成资料说明、错误提示与必要的家长帮助仍可见。

## 模型与配置

正常页面真实使用 `qwen3.8-max-0902`，地址为 `https://dashscope.aliyuncs.com/compatible-mode/v1`。已查官方模型、兼容参数及结构化输出文档，并通过实际调用确认此 Key 的模型权限与参数可用；没有静默换模型或用预写答案代替失败。

`config/runtime.json` 集中配置：`enable_thinking=false`、最大输出 1800 Token、温度 0.5、网络超时 28 秒、输入字节上限 42000。一次调用返回严格 JSON Schema：自然回答、话题、最多两条有原话依据的线索、实际参考的记忆 ID 和可选建议。代码只做格式、归属、存储及必要安全边界检查，不增加事实审核模型、修复循环或自动重试。

曾统一试用有界思考模式，出现仅返回回答片段、缺少其他字段的结果，耗时也增加。最终采用非思考模式与严格结构，截断或格式不完整时明确失败、保留问题，由用户决定重试。所有主题使用同一配置，没有逐题调参。

通用提示要求保留因果与条件、诚实说明没有看到现场、按语义理解反馈、先讲实际原因、仅按需类比/故事、前答有错可纠正。按照用户后续要求，对条件遗漏和强套类比做通用修正，没有为「不开灯」、影子或其他具体题目添加关键词、专用答案、句式门槛或新的审核链。

Key 只由后端在 API 鉴权边界从用户指定文件读取；没有返回聊天、进入前端、提示词、调用日志、源码或 Git。麦克风、云语音、模型搜索和其他收费服务均未启用。可选设备朗读保留且标为「未验证」，仅选择浏览器标记为本机的中文声音，本轮没有播放或验证。

## 记忆与数据一致性

真实问题先落盘，再请求模型。对话按档案与会话归属隔离；只取本次会话最近 14 条完成消息，以及最多 12 条当前档案的有效候选记忆。候选按话题相似、近期性和家长修订优先选取，最终是否相关由 LLM 按语义判断；没有向量数据库或第二次检索模型。

理解、困惑和偏好必须有本轮孩子逐字原话支持，代码核对摘录确实来自该表达。普通提问不会自动当成理解；系统解释过不等于孩子理解。记录是这次表达的线索，不是能力、性格或科学事实认证。话题内偏好不会自动扩大成长期偏好。

家长修改后的有效信息用于后续回答，撤回/删除项不再参与。修改档案、记录或提醒会使正在生成的旧资料回答失效，迟到结果不写回。回答详情可查看当时参考信息的快照；这是模型报告的使用证据，不代表证明其回答正确。历史快照与当前有效记忆分开保存。

本地存储采用文件锁、线程锁及原子写入。请求 ID 防连续点击重复调用；失败/停止后的重试复用原问题。启动时将未完成请求转为明确失败，允许页面恢复操作。删除记录保留来源对话，删除会话会隐藏相关原话与记忆；这些都是可恢复删除，磁盘并非彻底清除。来源会话恢复后关联线索恢复原状态。档案删除为可恢复归档。

## 实际验证结果

正常页面完成了：创建档案 → 提问与连续追问 → 没听懂/例子/故事/简化 → 结束及新会话 → 家长回看原话 → 修改线索和提醒 → 下一次相关回答参考最新提醒 → 查看亲子建议。

真实主题包括光与影子、种子/根/茎、冰融化、云与雨、叶子变化与浇水、蜗牛与自然表达反馈。记录保留了中间失败和不理想回答，没有逐题写模板、反复挑选最好一次或改写原回答。

- 家长在页面修改植物讲法提醒后，下一次浇水问题实际使用了更新的提醒；回答详情保留当时的最新文字。换到其他话题时没有引用该植物提醒。
- 「故事有点长，只想简单知道作用」被自然理解，回答缩短，并留下仅限当前话题、带准确原话的偏好记录。
- 早期回答存在条件遗漏、强套绘画类比和过强断言。通用修正后仍不能保证全部事实准确。最后一次指出前答问题时，模型承认并纠正了「咬不动」的断言，但新增的「大部分动物嫌麻烦」等概括仍不严谨。这些原话没有删除或包装成通过。
- 停止后刷新保留问题，供应商迟到的回答没有写入；双击重试仅产生一次新请求，原问题不重复。切换档案期间立即清空旧档案显示，避免昵称与内容短暂错配。
- 实际检查刷新、重启、返回、记录搜索、档案切换、表单保存/校验、记录修订/撤回/版本恢复、记录与会话删除/恢复、档案归档/恢复。两个普通页面同时操作、其中一个结束会话时，另一个过期发送会提示刷新并保留草稿，没有偷偷发起模型调用。
- 受控连接失败用独立临时进程在 HTTP 调用前注入一次错误，经正常页面验证错误提示、刷新和手动重试，重试实际请求模型。没有新增测试专用接口或提交该临时进程；这不等于真实供应商中断测试。HTTP 超时、未知用量、预算不足、格式失败及修改期间迟到结果另由离线回归覆盖。
- 桌面 1280×900 与窄屏 390×844 实际检查孩子端、家长端、记录详情和档案表单。修复档案切换显示、反馈触控尺寸、滚动阅读等问题。窄屏没有横向溢出；长页面可正常纵向滚动。孩子端窄屏截图采用实际窗口截图，避免整页截图改变窗口高度影响对话滚动位置。

185 项离线回归通过（167 项原有纯逻辑、18 项当前产品回归）。Python 编译、JavaScript 语法与 Git 空白检查通过。测试数量和 HTTP 成功不作为真实回答质量结论。
