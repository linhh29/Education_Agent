## 当前阻塞与最小后续方向

1. **家长日期存在真实错误（B）。** `ParentService.context/window` 依赖 LLM 选择相对日期；空档案“上周”实际选成 `2025-09-21 至 2025-09-27`。正文还多次按 UTC 日期讲成前一天，而界面按上海时间正确显示。RC21 的正确结果不能豁免此问题。应统一给模型的时间表达，检查相对日期选择，不需要换孩子模型或升级 memory。
2. **活动安全规则存在否定句误拦（B），最终彩排因此未通过。** 正常请求“由我拿叶子，不采摘、不品尝”返回“不适合直接操作”。`companion.py:safe_suggestion` 的危险词正则包含“尝”，独立可复现输入“由家长拿叶子，只看，不品尝”也返回 None。此次被拒绝的完整模型活动未保存，不能断言唯一触发字段；但规则误拦本身已确认。该函数与孩子端共用，按用户核心修改边界没有自行修改，也未另加审核模型。
3. **新内容偏差（B）：** 吸水解释把细缝与速度直接挂钩，没有条件。保留原失败答案，不用换题/重复挑选成功掩盖。RC04 属已有暂缓；新的偏差没有自动取得豁免。没有充分证据把问题归因于模型能力不足，也没有换模型。
4. **可保留或以后再处理（C）：** 拟人、回答略长、重复活动正文、`parent_confirmed`/`partial=true` 等内部字样偶尔进入生成正文、空建议只有标点；没有继续重做界面。家长历史目前只取最后6条消息，活动隔几轮可能接不回，应针对真实指代需求保留最近有效活动，而非新建 memory 框架。
