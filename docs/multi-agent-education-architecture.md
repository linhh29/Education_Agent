# 学龄前教育 Agent 的多智能体架构

## 目标

这套系统不是让多个大模型自由讨论或投票，而是由 Supervisor 按问题类型、回答模式、反馈和风险级别安排有边界的专职角色。目标是同时提高事实可靠性、学龄前适龄性、回答自然度、记忆可信度和家长可审计性，并控制儿童等待时间。

## 角色分工

| 角色 | 类型 | 是否在关键路径 | 职责 |
| --- | --- | --- | --- |
| 安全守护员 | 本地确定性规则 | 是 | 检查危险、隐私和家长介入边界 |
| 学习规划师 | LLM | 是 | 建立事实核心、认识状态、因果顺序和适龄预算 |
| 儿童讲解员 | LLM | 是 | 按本轮模式和最新儿童档案生成真实回答 |
| 回答检查员 | 本地门禁 + 按需 LLM | 是 | 检查事实、语言、模式结构和安全要求 |
| 复述观察员 | 本地门禁 + 按需 LLM | 否 | 只在孩子复述时核对理解证据 |
| 记忆整理员 | 本地证据规则 | 否 | 只保存通过交付门禁的回答和可核对证据 |
| 家长支持员 | 本地聚合，可扩展异步 LLM | 否 | 形成可回溯的趋势、摘要和陪伴建议 |

语音识别、语音合成、向量检索、重排和视觉理解属于工具层，不作为能够自行判断孩子是否掌握的认知 Agent。

## 四种回答模式

- `ask` 清楚解释：先给结论，再解释关键原因，至少三个自然完整句。
- `detail` 详细解答：按结论、因果步骤、具体说明和总结逐层展开，至少五个完整句。
- `story` 讲个故事：必须明确是故事，用情节承载事实，结尾回到真实原因。
- `observe` 一起观察：先解释真实原因，再提供低风险观察，并明确要求家长陪同。

切换模式会携带新的 `activityMode` 重新调用真实 LLM。每个模式有独立提示词、长度预算、句数和质量门禁，不是只改变界面标签。

## 延迟策略

1. 安全规则和本地质量门禁不调用 LLM。
2. 儿童讲解只保留一次主生成；格式失败或门禁失败时最多进行受限修复。
3. 独立 LLM 审核只用于容易出错、包含类比或需要复述判断的场景。
4. 家长摘要和非关键记忆聚合在回答交付后处理，不阻塞儿童端。
5. Agent 不进行无限互聊，不使用多模型投票，也不暴露思维链。

## 配置

角色组件支持独立配置，也可继承现有组件：

- `question_planner` 默认继承 `parent_analysis`
- `child_tutor` 默认继承 `child_answer`
- `quality_reviewer` 默认继承 `parent_analysis`
- `teachback_reviewer` 默认继承 `parent_analysis`

因此现有 `config/models.json` 无需增加 API Key 即可运行。若以后希望为某个角色使用不同模型，可以在对应角色配置中覆盖 `model_id`、`timeout_seconds` 等非凭据或凭据字段。

## 记忆原则

- 记忆库保存孩子档案、提问、反馈、复述证据、家长确认和通过门禁的认知记录。
- 旧回答不是答案缓存，下一轮仍由儿童讲解员依据孩子最新年龄和档案重新生成。
- `deliveryValidated=false` 时，记忆整理员跳过认知写入。
- 模型自评不能直接作为孩子已经掌握的证据。

## 可审计输出

每轮响应返回 `agentOrchestration`，只包含角色、状态、公开结果、耗时和失败状态，不包含 API Key、Base URL、模型内部推理或思维链。家长端可以查看完整角色分工和最近一轮参与状态；儿童端只展示亲和的“回答小队”。
